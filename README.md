# CastleyCrown Shopify Theme

CastleyCrown is a chess-themed Shopify storefront based on Dawn. It pairs royal burgundy, ivory, midnight, and gold accents with homepage copy tailored for chess boards, pieces, apparel, accessories, and player gifts.

## Brand direction

- **Store name:** CastleyCrown
- **Theme:** Chess, strategy, royal craftsmanship, tournament-night polish
- **Palette:** Ivory squares, midnight board tones, burgundy accents, and crown-gold calls to action
- **Homepage experience:** Hero messaging, chessboard brand panel, collection pathways, featured chess picks, strategy-focused story modules, FAQ content, newsletter signup, and trust/value columns

## Development

This remains a Shopify Online Store 2.0 theme. Use Shopify CLI and Theme Check for local development and validation.
